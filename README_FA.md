# حسابداری صبا | نسخه ۰.۵ — رابط کلاسیک هم‌سبک سپیدار

**نسخه ۰.۵ یک نمونه دسکتاپ عملیاتی برای آزمون است؛ انتشار تجاری تأیید نشده است.** هدف این مرحله بازطراحی محیط نرم‌افزار بر مبنای الگوی آشنای سپیدار، همراه با حفظ هسته مستقل حسابداری نسخه ۰.۴ بوده است.

## ظاهر جدید

- منوی نواری سبک کلاسیک ویندوز؛ نوار ابزار آبی کم‌رنگ همراه با میانبرهای قابل کلیک.
- ستون «سیستم‌ها» در سمت راست و دسته‌بندی «عملیات» و «فهرست و گزارش»؛ انتخاب ماژول از طریق سربرگ‌ها.
- انتخاب شرکت و سال مالی در بالای صفحه؛ وضعیت جاری پایین صفحه.
- میز کار فشرده، دسترسی سریع به اسناد و گزارش‌ها، حذف داشبورد بنفش قبلی.
- فرم سند حسابداری با سربرگ، تاریخ و شرح، اقلام بدهکار/بستانکار، جدول ردیف‌ها و کنترل تراز.
- جدول‌های پرردیف با سربرگ آبی و سطرهای فشرده برای استفاده سریع حسابدار.
- کلیدهای `Ctrl+N` برای ثبت سند، `Ctrl+L` فهرست اسناد و `Ctrl+T` تراز آزمایشی.

**این برنامه کپی کد، تصویر، لوگو یا نام تجاری سپیدار نیست**؛ هویت و کدهای برنامه متعلق به پروژه مستقل صبا هستند. زیرسیستم‌های تخصصی هنوز همان قابلیت‌های آزمایشی نسخه قبلی هستند.

## راه‌اندازی آزمایشی روی ویندوز ۱۰/۱۱

۱. ZIP را استخراج کنید.
۲. Python با کتابخانه استاندارد Tkinter را نصب کنید (Python 3.12 یا جدیدتر پشتیبانی‌شده پیشنهاد می‌شود).
۳. `run_demo.bat` را برای نمایش اطلاعات نمونه و محیط اصلی اجرا کنید.
۴. `run_finance_demo.bat` را برای کنترل چرخه پایان سال اجرا کنید.
۵. `run_windows.bat` حالت پایگاه داده دائمی است؛ **تا تأیید امنیت و صحت برنامه از اطلاعات واقعی استفاده نکنید**.

کد وابستگی خارجی زمان اجرا ندارد و از Tkinter و SQLite استاندارد استفاده می‌کند. فایل نصبی EXE هنوز ساخته نشده است. `build_exe_windows_optional.bat` فقط دستور ساخت آزمایشی تحت ویندوز است و نیاز به نصب جداگانه PyInstaller دارد.
