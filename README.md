# حسابداری صبا | Saba Accounting Desktop

پروژه مستقل نرم‌افزار حسابداری دسکتاپ فارسی.

**وضعیت:** نسخه مبنای توسعه `0.6.5` است؛ سورس کامل آن هنوز به مخزن منتقل نشده است.

## شاخه‌ها
- `main`: کد و نسخه‌های تأییدشده
- `develop`: توسعه، اصلاح و آزمون

## ملاحظات انتشار عمومی
هیچ سند استخراج‌شده اختصاصی، کد یا دارایی متعلق به شرکت سپیدار، اطلاعات واقعی مشتری، رمز، کلید خصوصی، پایگاه داده، پشتیبان یا اطلاعات حساس نباید منتشر شود. این پروژه ارتباط مالکیتی با سپیدار ندارد.

## معیار پذیرش
قابلیت‌ها فقط با اجرای آزمون و ثبت شواهد تکمیل‌شده محسوب می‌شوند؛ ساخت EXE و آزمون ویندوز مراحل مستقل هستند.
