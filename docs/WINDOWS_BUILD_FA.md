# ساخت برنامه ویندوزی

۱. روی ویندوز ۱۰ یا ۱۱، Python 3.12 یا جدیدتر را نصب کنید (Tkinter فعال باشد).
۲. در CMD پوشه پروژه را باز کرده و `py -3 -m unittest discover -s tests -q` اجرا کنید.
۳. در صورت موفقیت آزمون‌ها، برای ایجاد EXE، با آگاهی از مجوزهای ابزار بیرونی، PyInstaller را جداگانه نصب کنید: `py -3 -m pip install pyinstaller`.
۴. `build_exe_windows_optional.bat` را اجرا کنید. در صورت موفقیت فایل `dist\SabaAccountingFinanceV04.exe` تولید می‌شود.
۵. خروجی را روی ماشین ویندوزی تازه نصب‌شده، با کاربر محدود، روی نمایشگرهای مختلف و با داده آزمایشی آزمون کنید. **فایل EXE در بسته فعلی وجود ندارد و هنوز روی ویندوز واقعی ساخته نشده است.**

PyInstaller در لینوکس خروجی EXE ویندوز تولید نمی‌کند (ابزار بین سیستم‌عامل‌ها کامپایل متقاطع ندارد). تولید فایل به منزله تأیید امنیت یا آمادگی توزیع نیست.
