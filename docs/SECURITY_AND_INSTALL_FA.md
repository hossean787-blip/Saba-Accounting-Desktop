# نصب و امنیت نسخه توسعه‌ای پس از ۰.۶.۲

## نصب و راه‌اندازی امن در Windows 10/11

۱. خروجی Action با نام `SabaAccounting-windows-<commit>` را فقط از مخزن خود پروژه دریافت و هش SHA-256 آن را با گزارش ساخت مقایسه کنید.
۲. فایل EXE فعلاً امضای دیجیتال ندارد؛ هشدار SmartScreen محتمل است. برای انتشار عمومی باید گواهی Code Signing و فرایند امضای مستقل افزوده شود.
۳. فایل داده در `%LOCALAPPDATA%\SabaAccounting\saba_ledger.sqlite3` قرار می‌گیرد. دسترسی پوشه را به حساب Windows کاربر محدود و برای حفاظت در برابر سرقت فایل، BitLocker را فعال کنید.
۴. پیش از ورود اطلاعات واقعی، در خط فرمان پروژه `python main.py --bootstrap-admin` را اجرا کنید. رمز حداقل ۱۲ نویسه‌ای و غیرتکراری انتخاب کنید.
۵. بازیابی فقط به فایل جدید مجاز است؛ برای کنترل پشتیبان از `verify_backup_windows.bat` استفاده کنید.

## مدل امنیتی

- نقش مدیر: تمام عملیات مالی، پشتیبان و مدیریت کاربران/رخدادهای امنیتی.
- نقش حسابدار: خواندن، ثبت و قطعی‌کردن عملیات، خروجی و پشتیبان؛ بدون مدیریت کاربران.
- نقش مشاهده‌گر: فقط مشاهده و خروجی؛ هر عملیات تغییردهنده در لایه منطق تجاری رد می‌شود.
- نشست پس از ۳۰ دقیقه بی‌کاری یا حداکثر ۸ ساعت منقضی می‌شود. پنج رمز اشتباه حساب را ۱۵ دقیقه قفل می‌کند.
- رمزها با PBKDF2-HMAC-SHA256، نمک تصادفی ۳۲ بایتی و ۶۰۰٬۰۰۰ دور نگهداری می‌شوند. رخداد ورود موفق/ناموفق ثبت می‌شود و رمز یا داده مالی در رخداد امنیتی نوشته نمی‌شود.

## محدودیت صریح

SQLite رمزگذاری‌شده نیست. ورود برنامه مانع خواندن یک کپی آفلاین از فایل توسط مهاجم دارای دسترسی سیستم‌عامل نمی‌شود. BitLocker، مجوز NTFS، پشتیبان رمزگذاری‌شده و حساب Windows جداگانه برای هر کاربر الزامی‌اند. این خروجی هنوز آزمون پذیرش مستقل حسابداری ایران، امضای دیجیتال و آزمون نفوذ ندارد و انتشار تجاری تأیید نشده است.
